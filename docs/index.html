📋 データモデル

Client型の主要フィールド

  • aozoraId: あおぞらID（業務上のプライマリキー）
  • isWelfareEquipmentUser: 福祉用具利用フラグ（手動設定可能）
  • meetings: Meeting[] - 議事録配列
  • changeRecords: ClientChangeRecord[] - 変更情報配列
  • selectedEquipment: Equipment[] - 選定済み福祉用具配列
  • salesRecords: SalesRecord[] - 売上レコード配列

Equipment型のカスケードフィールド

  • category: 福祉用具の種類（13種類）
  • manufacturer: メーカー（75社）
  • name: 商品名（928商品）
  • taisCode: 商品コード（自動入力）
  • units: 月間単位数（自動入力）
  • wholesaler: 卸会社（6社: ニッケン、日本ケアサプライ、ニシケン、パラケア、野口、キシヤ）

Firestore保存フィールド (ClientEdits)

  • meetings: ユーザーが追加/編集した議事録
  • changeRecords: ユーザーが追加/編集した変更情報
  • plannedEquipment: 選定予定の福祉用具
  • selectedEquipment: 選定済みの福祉用具
  • keyPerson: キーパーソン情報
  • address: 住所
  • medicalHistory: 病歴
  • isWelfareEquipmentUser: 福祉用具利用フラグ
