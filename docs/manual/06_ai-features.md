# AI機能

WelfareAssist Proには4つのAI機能が搭載されています。いずれもGemini AIを使用します。

---

## 1. AI議事録生成

担当者会議・カンファレンス・訪問記録のメモを正式議事録に自動変換します。

### 利用場所

利用者詳細 → Tab3「議事録」

### 手順A：Meetメモから作成（推奨）

1. 「Meetメモから作成」ボタン（緑）をクリック
2. 以下のいずれかでメモを取込：

| タブ | 操作 | 使いどき |
|-----|------|---------:|
| Google Docs URL | URLを貼り付け → 「取得」 | Google Docsにメモを書いた場合 |
| テキスト貼り付け | テキストをそのまま貼り付け | コピーが手元にある場合 |
| ファイルアップロード | .txt または .pdf を選択 | ファイル形式のメモがある場合 |

3. プレビューでテキストを確認
4. 「この内容でAI議事録を作成」ボタンをクリック
5. AIが自動生成し、右側「AI生成サマリー」に表示

> **Google Docs URLを使う場合**：対象ドキュメントを「リンクを知っている全員が閲覧可」に設定してください。

### 手順B：手動入力後に生成

1. 「＋ 記録を追加」ボタンで新規レコードを作成
2. 「内容」欄にメモを入力
3. 「AI議事録を生成」ボタンをクリック

### 出力フォーマット

| 種別 | 出力項目 |
|-----|---------|
| 担当者会議・カンファレンス | 会議目的／出席者・所属／利用者の現状／協議内容／決定事項／今後の対応・役割分担／次回予定／特記事項 |
| その他（訪問等） | 訪問日時／訪問目的／利用者の状態／確認事項／対応内容／今後の予定／特記事項 |

## 2. 医療文書OCR

診断書・処方箋などを読み取り、テキストとして保存します。

### 利用場所

利用者詳細 → Tab2「病歴・医療情報」→「文書をアップロード」ボタン

### 手順

1. 「文書をアップロード」ボタンをクリック
2. PDF・PNG・JPG・WEBPを選択（最大20MB）
3. AIが自動でテキスト抽出（約30秒）
4. 内容を確認・修正して「保存」

---

## 3. 請求書OCR

卸会社からのPDF請求書を自動で読み取ります。

### 利用場所

売上・仕入突合 → 「請求書アップロード」タブ

### 手順

1. 卸会社を選択
2. PDFファイルをドラッグ＆ドロップ
3. AIが利用者名・金額・商品名を自動抽出（約30〜60秒）
4. 抽出結果を突合画面で確認

> **複数PDFの分割アップロード**: 同じ卸会社なら分割してアップロード可（自動マージ）

### 会社ごとの対応状況

| 卸会社 | 処理方式 |
|--------|---------|
| 日建リース工業 | 専用パーサー（高精度） |
| 野口株式会社 | AI読み取り |
| 株式会社ニシケン | AI読み取り / CSV取込 |
| パラマウントケアサービス | AI読み取り / CSV取込 |
| 日本ケアサプライ | AI読み取り / CSV取込 |
| 株式会社キシヤ | AI読み取り |

## 4. 福祉用具提案

利用者の状況から適切な福祉用具を提案します。

### 利用場所

利用者詳細 → Tab5「福祉用具選定」→「AI提案」ボタン

### 手順

1. 「AI提案」ボタンをクリック
2. 利用者の病歴・要介護度・現在の用具情報を元にAIが提案
3. 提案一覧から追加したい用具を選択

## よくある質問

**Q: AI生成に失敗する場合は？**
- ネットワーク接続を確認してください
- 生成には30〜60秒かかります。途中でページを離れないでください
- エラーが続く場合は手動入力に切り替えてください

**Q: 生成結果を修正できますか？**
- 右側の「AI生成サマリー」テキストエリアを直接編集できます
- 「保存」ボタンで保存してください

**Q: Google Docs URLが取得できない場合は？**
- ドキュメントの共有設定を確認してください（「リンクを知っている全員が閲覧可」）
- URLが正しい形式（`https://docs.google.com/document/d/...`）か確認してください
