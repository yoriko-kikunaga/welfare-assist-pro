# ベッド管理

自社所有のベッド・サイドレール・マットレスの在庫・貸出・QR管理・償却・クリーニング・監査ログを管理します。

左サイドバー「ベッド管理」ボタン（藍色）からアクセスします。

---

## 4つのタブ

| タブ | 内容 |
|-----|------|
| 在庫一覧 | 全アイテムの一覧・ステータス管理・状態変更操作 |
| セット管理 | 複数アイテムをセットとして管理・一括操作 |
| 償却・クリーニング | 12ヶ月償却計算・クリーニング記録 |
| 監査ログ | 全ステータス変更の履歴（追記専用） |

---

## 在庫一覧タブ

### ステータスの種類（9種類）

| ステータス | 意味 |
|----------|------|
| 倉庫保管 | 倉庫に保管中（使用可能） |
| 事務所保管 | 事務所に保管中（使用可能） |
| クリーニング前 | 返却後、クリーニング待ち |
| クリーニング中 | クリーニング処理中 |
| 介護保険貸与にて使用 | 介護保険レンタルで利用者に貸出中 |
| 自費にて使用 | 自費レンタルで利用者に貸出中 |
| 施設物品 | 施設の備品として使用中 |
| 販売済み | 利用者に販売済み |
| 破棄済み | 廃棄処分済み |

### 用途区分（5種類）

| 用途区分 | 説明 |
|---------|------|
| 介護保険 | 介護保険レンタル向け |
| 自費 | 自費レンタル向け |
| 販売 | 販売向け |
| 施設物品 | 施設備品 |
| 使用不可 | 故障・廃棄予定 |

> 次に遷移できるステータスは「用途区分 × 現在のステータス」の組み合わせによって自動的に絞り込まれます。

### アイテムの追加

1. 「＋ アイテムを追加」ボタンをクリック
2. 種別を選択（ベッド本体 / サイドレール / マットレス）
3. 管理コード・購入日・購入金額・月額償却・用途区分等を入力
4. 「保存」

> 管理コードは自動採番されます（BED-001, SR-001, MT-001形式）

### 状態変更操作

1. アイテムの「状態変更」ボタン（または行をクリック）
2. 遷移先ステータスを選択
3. 貸出先・変更日・備考等を入力
4. 「変更する」

> ステータス変更の内容はすべて監査ログに自動記録されます。

### QRコード

- 各アイテムにQRコードを発行できます
- 「QRコードを表示」→ 印刷または保存
- 「QRスキャン」ボタンでカメラを使ってQRコードを読み取り、アイテムを素早く検索できます

**QRスキャン手順**:
1. カメラへのアクセスを許可する
2. QRコードを枠内に収める
3. 自動で読み取り完了（操作不要）

### モバイル表示

スマートフォン・タブレットではカード形式で表示されます（デスクトップはテーブル形式）。

---

## セット管理タブ

### セットとは

ベッド本体・サイドレール・マットレスなど複数のアイテムをひとまとめにして管理する機能です。

### セットの作成

1. 「＋ セットを作成」ボタンをクリック
2. セット名を入力（例：「標準ベッドセットA」）
3. 含めるアイテムを選択
4. 「保存」

### セット一括操作

セット単位でステータス変更・貸出・返却が一括で行えます。

---

## 償却・クリーニングタブ

### 12ヶ月償却 レンタル先一覧

タブ最上部に、12ヶ月償却アイテムのレンタル先一覧を表示します。

| 表示項目 | 内容 |
|---------|------|
| レンタル先 | 貸出先名 |
| 貸出期間 | 開始日〜返却日（返却済の場合） |
| 累計レンタル月数 | 実際に貸し出していた月数の合計 |
| 残レンタル月数 | 12ヶ月 − 累計月数 |
| 残存簿価 | 月額償却 × 残レンタル月数 |

> 残存簿価は **カレンダー上の経過日数ではなく、実際にレンタルしていた月数** をもとに計算します。

- 貸出中の行：緑背景
- 返却済みの行：グレー背景

### 償却計算（全アイテム）

| 項目 | 内容 |
|-----|------|
| 月額償却 | 購入金額 ÷ 償却月数 |
| 累計償却額 | 実レンタル月数 × 月額償却 |
| 残存簿価 | 購入金額 − 累計償却額 |

### クリーニング記録

返却後のクリーニング記録（業者名・費用・期間）を管理します。

---

## 監査ログタブ

全てのステータス変更が時系列で記録されています（追記のみ・削除不可）。

| 表示項目 | 内容 |
|---------|------|
| 日時 | 変更が行われた日時 |
| 管理コード | 対象アイテムのコード |
| 変更内容 | 変更前ステータス → 変更後ステータス |
| 備考 | 変更時に入力したメモ |

---

## 旧データからの移行

以前の在庫データがある場合、「移行」機能で一括取込ができます（旧データは削除されません）。

---

## CSV出力

在庫一覧・償却一覧のCSVを各タブから出力できます。
