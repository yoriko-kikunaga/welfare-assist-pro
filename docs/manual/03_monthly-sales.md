# 月次売上処理

毎月の売上データを確認・確定し、CSVを出力する機能です。

左サイドバー「月次売上処理」ボタン（紫）からアクセスします。

---

## 3つのタブ

| タブ | データソース |
|-----|------------|
| 介護保険レンタル | カイポケCSVインポートで取込んだデータ |
| 自費レンタル | スプレッドシート連携または手動入力データ |
| 販売 | スプレッドシート連携または手動入力データ |

---

## 基本操作フロー

```
月度選択 → 事業所フィルター → データ確認 → CSV出力 → 確定
```

### 1. 月度の選択

画面上部のカレンダーで対象月を選択します。

### 2. 事業所フィルター

「全事業所」または特定の事業所（鹿児島・熊本・宮崎等）でフィルタリングできます。

> フィルターは利用者の「事業所」設定（Tab1で設定）に基づきます。

### 3. データ確認

各タブで以下の内容を確認します：

- 利用者名・品目・金額
- 利用者負担額・申請額（販売タブ）
- 対象件数・合計金額

### 4. CSV出力

「CSV出力」ボタンで対象月・対象事業所のデータをCSVファイルとして保存できます。

### 5. 確定

「確定」ボタンで当月データを確定します。

- 確定後はデータが固定され、元データの変更が反映されなくなります
- 解除する場合は「確定解除」ボタンをクリック
- 3種類（介護保険・自費・販売）をそれぞれ個別に確定できます

## 金額内訳の列構成（販売タブ）

販売CSVには以下の列が出力されます。

| 列 | 計算式 | 備考 |
|----|--------|------|
| 小計 | 単価 × 数量 | |
| 消費税 | 小計 × 税率（切り捨て） | 税区分: 10% / 軽8% / 非課税。税込商品は0 |
| 税込金額 | 小計 + 消費税 | |
| 送料（税抜） | 手動入力 | 税抜き扱い |
| 送料消費税 | 送料 × 10%（四捨五入） | 送料0の場合は0 |
| 調整額 | 手動入力（±） | 端数調整用 |
| **総計** | 税込金額 + 送料（税抜）+ 送料消費税 + 調整額 | 利用者負担・申請額の計算基準 |

---

## 利用者負担額の計算ルール（販売タブ）

| 負担区分 | 利用者負担額 | 申請額 |
|---------|------------|--------|
| 自己負担０（日常生活給付） | 0円 | 総計 |
| 一部負担（日常生活給付） | 上限額 | 総計 - 上限額 |
| 1〜3割負担（受領委任払い） | 総計×割合（上限額以内） | 総計 - 利用者負担額 |
| 全額負担（償還払い） | 総計 | 0円 |

## 毎月の作業チェックリスト

- [ ] カイポケCSVインポート済み（介護保険レンタルタブ）
- [ ] 自費レンタル・販売データが最新か確認（前日 00:00 自動更新）
- [ ] 事業所フィルターを正しく設定してCSV出力
- [ ] 3タブすべて確定
