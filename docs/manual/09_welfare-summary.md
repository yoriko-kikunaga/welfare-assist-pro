# 09. 福祉用具集計

## 概要

`isWelfareEquipmentUser = ON` に設定されている利用者の福祉用具利用状況を、施設別・Status別・事業所別の3つの切り口で一覧表示します。読み取り専用の集計ページです。

**アクセス方法**: 左サイドバー「福祉用具集計」ボタン（teal系）

---

## 3つのタブ

| タブ | サブタブ | 集計軸 |
|------|---------|--------|
| 施設別 | 在宅・各施設名 | `facilityName` でグループ化（在宅を先頭に表示） |
| Status別 | 介護保険レンタル・自費・併用・未設定 | `selectedEquipment.status` でグループ化 |
| 事業所別 | 鹿児島（ACG）・福岡（Lichi） | `office` でグループ化・フラット一覧 |

---

## 事業所フィルター

- **施設別・Status別タブ**: 画面上部に「全事業所 / ACG / Lichi」の絞り込みボタンを表示
- **事業所別タブ**: サブタブ自体がフィルターとして機能するため、上部フィルターは非表示

---

## 表示フィールド

各利用者ごとに以下の情報が表示されます：

| フィールド | 内容 |
|-----------|------|
| あおぞらID | 利用者識別子（例: AZ-0001） |
| 要介護度 | 申請中・要支援1-2・要介護1-5 |
| 施設名 | 在宅の場合「在宅」、入居施設の場合は施設名 |
| 居室 | 施設別タブのみ表示 |
| 福祉用具件数 | 現在選定されている福祉用具の件数 |
| 居宅介護支援事業所 | 担当ケアマネ事務所 |
| 担当CM | 担当ケアマネジャー名 |
| 生活保護バッジ | `paymentType = '生保'` の場合にバッジ表示 |

---

## データの特性

- **読み取り専用**: このページからデータを編集することはできません
- **定時更新の影響**: 表示されるフィールドはすべて `clientEdits` の保持対象（`office`, `careSupportOffice`, `careManager`, `paymentType` 等）のため、定時更新後も保持されます
- **対象利用者**: 左サイドバーの「福祉用具」フィルターと同じく `isWelfareEquipmentUser = true` の利用者のみ

---

## よくある使い方

- 施設別タブ：施設入居中の福祉用具利用者の一覧確認
- Status別タブ：介護保険レンタル・自費・併用の内訳確認
- 事業所別タブ：事業所ごとの担当利用者一覧の確認・共有
