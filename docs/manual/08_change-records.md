# 変更情報一覧

新規・入院・退院・解約・デモなどの変更情報を横断的に確認し、CSVやスプレッドシートに出力する機能です。

左サイドバー「変更情報一覧」ボタン（青色）からアクセスします。

---

## 概要

各利用者のTab4「変更情報」で登録したレコードを、全利用者分まとめて確認できます。

- 期間・事業所・情報種別でフィルタリング
- CSV出力（集計業務用）
- Googleスプレッドシートへの追記出力

---

## 基本操作

### 1. フィルター設定

画面上部で以下を設定します：

| フィルター | 説明 |
|----------|------|
| 開始日・終了日 | 対象期間を指定 |
| 事業所 | 全事業所または特定の事業所 |
| 情報種別 | 新規・入院・退院・解約・変更あり・その他・デモ |

### 2. 一覧の確認

条件に合った変更情報が表示されます。

| 列 | 内容 |
|----|------|
| 利用者名 | クリックで利用者詳細へ |
| 事業所 | 利用者の担当事業所 |
| 情報種別 | 新規・入院・退院・解約・変更あり・その他・デモ |
| 日付 | 変更日（請求開始日・停止日・デモ開始日等） |
| 卸会社連絡状況 | 連絡済み/未連絡など |
| 備考 | 自由入力メモ |

### 3. CSV出力

「CSV出力」ボタンで現在の表示内容をCSVとして保存します。

- 文字コード：UTF-8（BOM付き）
- フィルター条件が反映されます
- デモ種別の場合はデモ開始日・デモ終了日列が含まれます

### 4. スプレッドシート出力

「スプレッドシートに書き出し」ボタンで、Googleスプレッドシートに直接データを書き出します。

**動作仕様（追記モード）**

- **初回実行時**: ヘッダー行＋全レコードを書き込みます
- **2回目以降**: レコードIDをキーに既存行を判定し、**新しいレコードのみ末尾に追記**します（既存データは上書きされません）
- **対象データ**: 2025年11月1日以降のレコードのみ出力されます（過去の履歴データは除外）

**出力列**

| 列 | 内容 |
|----|------|
| レコードID | 重複排除のためのキー |
| 利用者名 | 利用者氏名 |
| あおぞらID | 利用者識別子 |
| 情報種別 | 変更情報の種別 |
| 記録日 | 変更が記録された日付 |
| 請求停止日 | 入院・解約時 |
| 請求開始日 | 新規・退院時 |
| デモ開始日 | デモ種別のみ |
| デモ終了日 | デモ種別のみ |
| データ連携日 | 各種別の主要日付 |
| 卸会社連絡状況 | 連絡済み/未連絡など |
| 備考 | 自由入力メモ |
| 施設名 | 入居施設名 |

> **注意**: スプレッドシートへの書き出しには管理者がサービスアカウントに編集権限を付与する必要があります。

---

## 情報種別の説明

| 種別 | 主な使いどき | カード色 |
|-----|------------|--------|
| 新規 | 新規利用者の請求開始時 | 緑 |
| 入院（サービス停止） | 入院による福祉用具レンタル一時停止時 | オレンジ |
| 退院（サービス開始） | 退院後の再開時 | 青 |
| 解約 | レンタル解約時 | 赤 |
| 変更あり | 用具変更・ケアマネ変更など | 水色 |
| その他 | 上記に当てはまらない変更 | 水色 |
| デモ | 用具のデモ貸出期間を記録 | 水色 |

---

## よくある使い方

- 月初に先月分の変更情報をCSV出力 → 請求処理に活用
- 卸会社への連絡漏れチェック（卸会社連絡状況列を確認）
- レセプトチェック時の入退院情報の照合
- スプレッドシートへの追記出力 → 担当者間の情報共有・履歴管理
