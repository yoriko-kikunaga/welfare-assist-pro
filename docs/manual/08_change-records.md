# 変更情報一覧

新規・入院・退院・解約などの変更情報を横断的に確認し、CSVやスプレッドシートに出力する機能です。

左サイドバー「変更情報一覧」ボタン（青色）からアクセスします。

---

## 概要

各利用者のTab4「変更情報」で登録したレコードを、全利用者分まとめて確認できます。

- 期間・事業所・情報種別でフィルタリング
- CSV出力（集計業務用）
- Googleスプレッドシートへの直接書き出し

---

## 基本操作

### 1. フィルター設定

画面上部で以下を設定します：

| フィルター | 説明 |
|----------|------|
| 開始日・終了日 | 対象期間を指定 |
| 事業所 | 全事業所または特定の事業所 |
| 情報種別 | 新規・入院・退院・解約・変更 |

### 2. 一覧の確認

条件に合った変更情報が表示されます。

| 列 | 内容 |
|----|------|
| 利用者名 | クリックで利用者詳細へ |
| 事業所 | 利用者の担当事業所 |
| 情報種別 | 新規・入院・退院・解約・変更 |
| 日付 | 変更日（請求開始日・停止日等） |
| 卸会社連絡状況 | 連絡済み/未連絡など |
| 備考 | 自由入力メモ |

### 3. CSV出力

「CSV出力」ボタンで現在の表示内容をCSVとして保存します。

- 文字コード：UTF-8（BOM付き）
- フィルター条件が反映されます

### 4. スプレッドシート出力

「スプレッドシートに書き出し」ボタンで、Googleスプレッドシートに直接データを書き出します。

> スプレッドシートIDは管理者が設定します。

---

## 情報種別の説明

| 種別 | 主な使いどき |
|-----|------------|
| 新規 | 新規利用者の請求開始時 |
| 入院（サービス停止） | 入院による福祉用具レンタル一時停止時 |
| 退院（サービス開始） | 退院後の再開時 |
| 解約 | レンタル解約時 |
| 変更 | 用具変更・ケアマネ変更など |

---

## よくある使い方

- 月初に先月分の変更情報をCSV出力 → 請求処理に活用
- 卸会社への連絡漏れチェック（卸会社連絡状況列を確認）
- レセプトチェック時の入退院情報の照合
