# 利用者管理

## 利用者を探す

### 検索
左サイドバーの検索ボックスに **氏名・カナ・あおぞらID** を入力すると絞り込めます。

- 例：`田中`、`タナカ`、`AZ-0001`

### フィルター
- **全員**：全利用者を表示
- **福祉用具**：福祉用具利用中のみ表示（通常はこちらを使用）

---

## 利用者詳細（7タブ）

利用者名をクリックすると詳細画面が開きます。画面上部に7つのタブがあります。

> **保存について（2026-08-26〜）**: 入力内容は**自動保存されません**。編集したら必ず画面右上の「**保存する**」ボタンを押してください。未保存の変更がある間は「未保存の変更があります」のバッジが表示されます。保存せずに別の利用者を選んだり、他のページに移動したり、タブを閉じようとすると確認のダイアログが表示されます（「保存して移動」「保存せず移動」「キャンセル」から選べます）。

---

### Tab1：基本情報

利用者の基本的な属性情報を管理します。

| フィールド | 説明 |
|-----------|------|
| 事業所 | 担当事業所（鹿児島（ACG）・福岡（Lichi）） |
| 入居施設名 | 入居施設名（在宅の場合は空欄） |
| 居室番号 | 施設の居室番号 |
| 在宅区分 | 自宅 / 外部施設 / その他 |
| 福祉用具利用者 | 福祉用具（介護保険・自費レンタル・販売すべて含む）の利用者か |
| レセプトチェック対象 | レセプトチェックの強制追加／強制除外／自動判定 |
| 請求区分 | 自費レンタル / 介護保険レンタル / 併用 |
| 居宅介護支援事業所 | ケアマネ所属事業所名 |
| 担当CM | 担当ケアマネジャー名 |
| 要介護度 | 申請中〜要介護5 |
| 負担割合 | 1〜3割 |
| 介護保険被保険者証／負担割合証 | 確認済 / 未確認 |
| 支払い区分 | 非生保 / 生保 |
| カイポケ登録状況 | 登録済み・未登録等 |

> 「福祉用具利用者」「レセプトチェック対象」は生年月日・性別の下に縦並びで、その右に「請求区分」を配置しています。

**編集方法**
1. 右上「編集」ボタンをクリック
2. 内容を変更
3. 「保存」ボタンをクリック

> 編集した内容は即座に保存され、毎日の自動更新後も保持されます。

**変更履歴（🕐タイムライン）**

事業所・要介護度・請求区分など追跡対象の項目を変更すると、実効日を入力するダイアログが表示され、各項目横の🕐ボタンから過去の変更履歴を確認できます。

**施設契約情報（生年月日・性別の下）**

施設への入居・退去情報（Kintone連携）を表示します。施設入居者のみ表示され、在宅の方は「情報はありません」と表示されます。
> ここはレンタルの契約情報（Tab4「利用者新規・変更情報入力」の「レンタル契約情報」）とは別系統です。混同しないようご注意ください。

### Tab2：病歴・医療情報

利用者の病歴・服薬情報などを管理します。

**手動入力**
1. 「編集」ボタン → テキストエリアに入力 → 「保存」

**医療文書OCR（AI読み取り）**
1. 「文書をアップロード」ボタン
2. 診断書・処方箋などのPDF/画像（PNG・JPG）を選択
3. AIが自動でテキスト抽出（約30秒）
4. 内容を確認・修正して「保存」

> 対応形式：PDF・PNG・JPG・WEBP（最大20MB）

---

### Tab3：議事録

担当者会議・カンファレンス・訪問記録を管理します。

#### 方法①：手動入力で記録を追加

1. 「＋ 記録を追加」ボタン
2. 種別・日付・記録者・場所・出席者・内容を入力
3. 「AI議事録を生成」ボタンで正式フォーマットに自動変換（任意）
4. 「保存」

#### 方法②：Meetメモから作成（推奨）

Google Meetの会議メモから直接AI議事録を作成できます。

1. 「Meetメモから作成」ボタン（緑）をクリック
2. 以下のいずれかでメモを取込

| タブ | 操作 | 使いどき |
|-----|------|---------|
| Google Docs URL | URLを貼り付け→「取得」 | Google Docsにメモを書いた場合 |
| テキスト貼り付け | Google Docsからコピペ | テキストが手元にある場合 |
| ファイルアップロード | .txt または .pdf を選択 | ファイル形式のメモがある場合 |

3. 取込テキストのプレビューを確認
4. 「この内容でAI議事録を作成」→ AIが自動的に正式議事録を生成

> **Google DocsのURL取込を使う場合**：対象のGoogle Docsを「リンクを知っている全員が閲覧可」に設定してください。

#### 議事録の種別と出力フォーマット

| 種別 | AIが生成するフォーマット |
|-----|----------------------|
| 担当者会議（新規・更新・退院時） | 会議目的／出席者・所属／利用者の現状／協議内容／決定事項／今後の対応・役割分担／次回予定／特記事項 |
| カンファレンス時 | 同上（8項目） |
| その他（訪問等） | 訪問日時／訪問目的／利用者の状態／確認事項／対応内容／今後の予定／特記事項（7項目） |

### Tab4：変更情報

新規・入院・退院・解約・デモなどの変更情報を記録します。

**追加方法**
1. 「＋ 変更情報を追加」ボタン
2. 情報種別を選択
3. 日付・卸会社連絡状況・備考を入力
4. 「利用区分」（自費レンタル／介護保険レンタル／販売）にチェック　※初期状態はすべて未選択のため、必ず該当するものにチェックしてください
5. 「保存する」

> 「情報を追加」ボタンを押した直後のレコードは、**「入力中」カード（黄色）** として最上部に固定表示されます。保存またはキャンセルするまでこの位置に留まります。

**情報種別と主な入力項目**

| 種別 | 主な入力項目 |
|-----|------------|
| 新規 | 請求開始日 |
| 入院（サービス停止） | 請求停止日、卸会社停止連絡状況 |
| 退院（サービス開始） | 請求開始日、卸会社再開連絡状況 |
| 解約 | 請求停止日 |
| 変更あり / その他 | 変更内容・備考 |
| デモ | デモ開始日・デモ終了日 |

**セクションの表示順**

| セクション | 対象種別 |
|-----------|---------|
| ① 入院・退院情報 | 入院・退院（日付でペアリング表示） |
| ② その他 | 変更あり・その他・デモ（水色カード） |
| ③ レンタル契約情報 | レンタルの新規・解約 |

> 施設への入居・退去情報（施設契約情報）は **基本情報タブ（Tab1）** に移動しました。このタブの「レンタル契約情報」は福祉用具レンタルの新規・解約のみを扱います。

### Tab5：福祉用具選定

レンタル・販売している福祉用具の一覧を管理します。

**表示される種別**
- 介護保険レンタル（カイポケCSVインポートで取込）
- 自費レンタル（スプレッドシート連携または手動入力）
- 販売（スプレッドシート連携または手動入力）

**手動で福祉用具を追加する場合**
1. 「＋ 機器を追加」ボタン
2. 種類を選択（介護保険レンタル・自費レンタル・販売）
3. 属性を選択（下記参照）
4. 品目・メーカー・商品名を選択（マスターから自動入力）
5. 月額・数量・開始日等を入力
6. 「保存」

**属性の選択肢**（突合画面で「仕入不要」扱いにするかどうかを決める重要な設定）

| 選択肢 | 意味 | 突合への影響 |
|-------|------|-------------|
| 自社物件 | 自社で所有しており、卸業者への支払いが発生しない用具 | 突合画面で「仕入不要（自社ベッド）」表示になり、卸請求との照合対象から外れる |
| リース物件 ／ 販売の場合は「卸仕入により販売」 | 卸業者から仕入れて提供している用具（通常はこちら） | 卸請求と照合される（通常の突合対象） |
| 設定しない | まだ判断がつかない場合 | あとで編集モーダルから設定可能。突合画面では「ー」表示 |

> **注意**：シューズ・サポーター・日用品など、自社所有でもリースでもない一般的な販売品目に誤って「自社物件」を選ぶと、実際は卸請求があるのに突合対象から外れてしまいます。判断に迷う場合は必ず「設定しない」を選び、あとで確認してください。

### Tab6：売上管理

該当利用者の月別売上・仕入情報を確認できます。

- 月別の売上金額・仕入金額・粗利を一覧表示
- 突合済みデータが自動で反映されます
- 確定済みの月は変更できません

---

### Tab7：書類管理

利用者に関連するPDF書類（計画書・モニタリング等）をアップロード・閲覧・削除できます。

**アップロード方法**
1. 「書類を追加」ボタンをクリック
2. 書類の種類を選択（計画書 / モニタリング / その他）
3. メモ（任意）を入力
4. PDFファイルを選択（最大20MB）
5. アップロード完了後、一覧に表示されます

**書類の種類（バッジ色）**

| 種類 | バッジ色 |
|-----|---------|
| 計画書 | 青 |
| モニタリング | 緑 |
| その他 | グレー |

**操作ボタン**

| ボタン | 動作 |
|-------|------|
| 開く | PDF を別タブで表示 |
| 削除 | 書類を削除（確認ダイアログあり） |

> PDFファイルのみ対応（最大20MB）。アップロードした書類は Firebase Storage に保存されます。
