# レセプトチェック

介護保険レンタルの請求前に、請求内容を確認するチェックリスト機能です。

左サイドバー「レセプトチェック」ボタン（薔薇色）からアクセスします。

---

## 概要

従来スプレッドシートで管理していた請求前確認作業をアプリ内で完結できます。

- 介護保険レンタルがある利用者を**ページを開くたびに自動で最新化**
- 入院日・退院日・解約日が変更情報から自動設定
- チェック状態はクリックで即時保存（自動保存）
- リストは月をまたいで**継続使用**（一度追加された方はそのまま残る）

---

## 基本操作

### 1. 月度・事業所の選択

画面上部で対象月と事業所を選択します。

> 事業所を切り替えてもデータは消えません（保存キーは「全事業所」固定）。

### 2. ページを開いたときの自動処理

ページを開くたびに以下が自動実行されます：

1. 保存済みリストを読み込み
2. 事業所・拠点・生保フラグ・入退院日等を**最新の利用者データで上書き**
3. 退院日が該当月より前の場合、入院日・退院日を空白にクリア
4. 以下の条件に該当する利用者を自動除外（強制追加設定を除く）
   - 自費レンタルのみ（介護保険レンタルが一件もない）
   - 福祉用具利用者チェックがOFFになっている
   - 解約日が該当月より前に入力されている
5. リストにまだ載っていない新規対象者を自動追加
6. あかさたな順でソート・自動保存

### 3. データ取込ボタン

「データ取込」ボタンをクリックすると、同じ処理を手動で実行します。

取込される情報：
- 利用者名・あおぞらID・読み仮名
- 事業所・拠点
- 居宅介護支援事業所（ケアマネ事務所）
- 単位数合計（カイポケCSVインポート後に反映）
- 入院日・退院日・解約日（変更情報から自動抽出）
- 生保フラグ（paymentType=生保の場合）
- 利用初回日（変更情報「新規」の最古の請求開始日）

> **再取込時**: 既存のチェック状態・手動入力した単位数・利用初回日・解約日は保持されます。

### 4. チェックリストの確認・入力

| 列 | 内容 |
|----|------|
| 利用者名 | クリックで利用者詳細へ |
| 事業所・拠点 | Tab1の設定から自動取得 |
| 居宅介護支援事業所 | Tab1の設定から自動取得 |
| 単位数 | 直接入力可能（再取込時も保持） |
| 利用初回日 | 直接入力可能（YYYY-MM-DD形式） |
| 入院日・退院日 | 変更情報から自動抽出（読み取り専用） |
| 解約日 | 直接入力可能（YYYY-MM-DD形式）。セル右の鍵アイコンをクリックでロック |
| 各チェック項目 | クリックで ON/OFF（自動保存） |

> **解約日ロック**：転居等で誤った解約日が自動上書きされてしまう場合に使用します。ロック中はページ開封時の自動最新化をスキップし、手動入力値を保持します。ロックは月度更新時に自動解除されます。

### 5. 検索・フィルター

- **検索バー**：利用者名・居宅介護支援事業所で部分一致検索
- **事業所ドロップダウン**：事業所でフィルタリング（データは全事業所で共通保存）
- **ヘッダークリック**：クリックで昇順→降順→解除の3段階ソート

### 6. 月度更新

解約が当月内に完了した利用者をリストから除外し、翌月データへ引き継ぎます。

1. 「月度更新」ボタン（琥珀色）をクリック
2. 除外される利用者の一覧が表示される
3. 確認して「実行」

**除外対象**：解約日が「**当月内**」の利用者のみ除外されます。翌月以降が解約予定の利用者はそのまま残ります。

**翌月への引き継ぎ**：月度更新後、残存リストの単位数が翌月データに自動反映されます。
- 翌月データがすでにある場合 → 単位数を上書き（チェック状態等は保持）
- 翌月データがない場合 → 残存リストを初期値として保存（チェック・入退院日はリセット、利用初回日は保持）

**解約日ロックの自動解除**：解約日セルに鍵アイコンが付いている利用者は、月度更新時にロックが自動解除されます（翌月で正しい解約日が再取込されるよう）。

> 月度更新後に再度追加したい場合は「データ取込」を実行してください。

### 7. CSV出力

「CSV出力」ボタンで現在のチェックリストをCSVとして保存できます。

- 文字コード：UTF-8（BOM付き）
- チェック状態：○（チェックあり）/ 空白（チェックなし）

## ピックアップ対象の条件

### 追加される利用者（以下A〜Dのいずれかに該当）

| 条件 | 内容 | 対象ケース |
|------|------|-----------|
| **A** | 「新規」変更情報の請求開始日が2026年2月以降かつ当月末以内 | 今月・直近に新規開始した方 |
| **B** | 介護保険レンタルあり（期間問わず）＋「新規」変更情報あり（日付問わず） | 継続中で変更履歴がある方 |
| **C** | 用具データなし＋「新規」変更情報の請求開始日が2025年1月以降 | カイポケCSVインポート前の新規利用者 |
| **D** | 福祉用具チェックON＋介護保険レンタルが前月以降に有効 | 変更情報のない旧来からの継続利用者 |

### 除外される利用者（新規追加時）

- 当月開始前に「解約」の請求停止日がある
- 自費レンタルのみ（介護保険レンタルが一件もない）
- 福祉用具利用者チェックがOFF
- `receiptCheckTarget = 強制除外` に設定されている

### 自動除外（ページ開封時に既存リストにも適用）

- 自費レンタルがあり、かつ介護保険レンタルが一件もない利用者
- 福祉用具利用者チェックがOFF になっている利用者
- 解約日（手動入力・変更情報いずれも）が該当月より前の利用者
- `receiptCheckTarget = 強制除外` に設定されている利用者

> **強制追加（`receiptCheckTarget = 強制追加`）に設定されている利用者はすべての除外条件をバイパスし、常にリストに残ります。**

## レセプトチェック対象フラグ（手動設定）

各利用者の**基本情報タブ（編集モード）**に「レセプトチェック対象」チェックボックスがあります。

| 状態 | 表示 | 動作 |
|------|------|------|
| 未設定（初期値） | 自動判定 | A〜D条件による自動判定に任せる |
| ✓ チェックあり | **強制追加** | 条件・除外フィルタに関わらず常にリストに入る |
| □ チェックなし（明示的に外した） | **強制除外** | 条件に関わらず常にリストから外れる |

**使いどき**:
- レセプト前に特定の利用者を必ず含めたい → 強制追加
- 自動判定で追加されてしまう利用者を恒久的に除外したい → 強制除外
- 設定をリセットして自動判定に戻したい → 編集モードで「自動判定」状態（indeterminate）には現在直接戻せないため、一度チェックありにしてから画面をリロードするか担当者に相談

> フラグは定時更新後も保持されます。

---

## 入院日・退院日・解約日の表示ルール

| 条件 | 表示内容 |
|------|---------|
| 当月に複数件あり | すべての日付をカンマ区切りで表示（昇順） |
| 当月の件数が1件 | その日付を表示 |
| 当月の件数が0件 | 最新の1件のみ表示（参考情報） |

---

## データの保存と定時更新の関係

| 項目 | 定時更新の影響 |
|------|-------------|
| チェック状態 | **影響なし**（Firestore `receiptChecks` コレクションに独立保存） |
| 手動入力した単位数・日付 | **影響なし** |
| 事業所・拠点・生保フラグ | ページ開封時に最新化（定時更新後に変わると次回反映） |
| 入院日・退院日・解約日 | ページ開封時に最新化（変更情報が更新されると次回反映） |
| 利用者リスト（誰が載っているか） | **影響なし**（ページ開封時の自動判定のみで変わる） |

---

## よくある確認ポイント

- カイポケCSVインポート後にページを開き直すと、単位数が最新化される
- 月度更新前に、解約した利用者のチェックを完了させておく
- 単位数を手動修正した場合、再取込後も修正値が保持されることを確認
- CSVは請求作業前に必ず出力・保管しておく
