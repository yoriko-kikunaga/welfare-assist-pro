# 売上・仕入突合

卸会社からの請求書と社内売上データを突合し、粗利を算出する機能です。

左サイドバー「売上・仕入突合」ボタン（青緑）からアクセスします。

---

## 対応している卸会社

| 卸会社 | PDF取込 | CSV取込 |
|--------|--------|--------|
| 日建リース工業 | ○ | - |
| 野口株式会社 | ○ | - |
| 株式会社ニシケン | ○ | ○ |
| パラマウントケアサービス | ○ | ○ |
| 日本ケアサプライ | ○ | ○ |
| 株式会社キシヤ | ○ | - |

---

## 突合フロー

```
月度選択 → 売上抽出 → 請求書アップロード → 名前マッチング → 粗利確認 → CSV出力 → 確定
```

---

## 手順

### 1. 月度・卸会社の選択

画面上部で対象月と卸会社を選択します。

### 2. 請求書のアップロード

「請求書アップロード」タブを開き、各卸会社の請求書をアップロードします。

**PDFの場合**
- ドラッグ＆ドロップまたはクリックでファイル選択
- AIが自動でテキストを読み取り（約30〜60秒）
- 同じ卸会社のPDFは複数分割してアップロード可能（自動マージ）

**CSVの場合（ニシケン・パラマウント・日本ケアサプライ）**
- .csvファイルを選択
- 自動でパース（AIは使用しない）

### 3. 名前マッチング

OCR読み取り後、利用者名の自動マッチングが行われます。

- **自動マッチング済み**：そのまま次へ
- **未マッチ**：「未マッチ利用者」一覧に表示される

**未マッチの手動対応**
1. 未マッチ利用者名の横にある「利用者を選択」
2. 検索して正しい利用者を選択
3. 以降は自動的に学習・マッチングされます

### 4. インライン紐づけ編集

CSVの再インポートなしで、画面上で直接マッチングを修正できます。

| タブ | 操作 | 内容 |
|-----|------|------|
| 仕入のみ | 「紐づけ」ボタン | 未紐づけの仕入を利用者に紐づける |
| 突合済み | 鉛筆アイコン | 紐づけの変更・解除 |
| 売上のみ | 「仕入紐づけ」ボタン | 売上に対応する仕入を手動選択 |

### 5. 粗利の確認

3つのタブで突合結果を確認します：

| タブ | 内容 |
|-----|------|
| 突合済み | 売上と仕入が紐づいた明細（粗利計算済み） |
| 売上のみ | 仕入データのない売上（粗利＝売上額） |
| 仕入のみ | 売上データのない仕入（要確認） |

> **附属品（サイドレール等）**: ベッド本体に複数の附属品がある場合、1つの売上に対して複数の仕入が紐づきます。突合済みタブで「┗」マークの行が附属品です。

### 6. CSV出力

「CSV出力」ボタンで突合結果をCSVとして保存できます。

**CSV修正後の再インポート**
1. 出力したCSVをExcelで修正（あおぞらIDを追記・変更）
2. 「突合CSVインポート」ボタンで再インポート
3. 修正内容が反映されます

### 7. 確定

「仕入確定」で各卸会社のデータを確定します。
全社確定後に「月次確定」が可能になります。

---

## 確定後の変更

確定済みのデータは変更できません。修正が必要な場合：
1. 「仕入確定解除」→「月次確定解除」の順で解除
2. 修正後に再度確定

---

## よくある確認ポイント

- 請求書合計金額とOCR読み取り合計が一致しているか（画面上に差額表示）
- 「仕入のみ」タブに大量の未紐づけデータが残っていないか
- 翌月に持ち越される前に月次確定まで完了させること

## 利用者別突合セクション

既存の突合セクションの下部に、**介護保険レンタル・販売・自費レンタル**の3種類の利用者別突合セクションが表示されます（請求書アップロード済みの場合）。

### 目的

カイポケの品目と卸請求の品目を利用者単位・品目単位で照合し、請求漏れや金額不一致を確認します。

### 表示条件

| セクション | 対象利用者 |
|---|---|
| 介護保険レンタル（青） | 当月アクティブな介護保険レンタルがある利用者 |
| 販売（紫） | 当月納品日の販売品目がある利用者 |
| 自費レンタル（ティール） | 当月アクティブな自費レンタルがある利用者 |

### 各セクションの操作

#### 会社ブロックの展開

卸会社名をクリックすると利用者一覧が展開されます。

- 差額あり → 赤背景
- 紐づけ保存済み → 緑背景 ＋「紐づけ済」バッジ
- 一致 → 白背景

#### 品目の紐づけ（詳細モーダル）

「詳細」または「確認・編集」ボタンをクリックするとモーダルが開きます。

**モーダルでできること**

- 弊社品目と卸品目の対応を確認
- 卸品目の追加（「卸品目を追加」ボタン → ドロップダウンで選択）
- 卸品目の紐づけ解除（× ボタン）
- 1:N対応（1つの弊社品目に複数の卸品目を紐づけ可能）

**保存**

「紐づけを保存」ボタンで Firestore に保存されます。**翌月以降も自動的に同じ紐づけが適用**されます。

> 卸請求書に同じ卸品目名が複数ある場合（返品・新規が混在）、個別に紐づけを行ってください。

#### 会社単位の確定

全利用者の確認が完了したら「確定する」ボタンで会社単位を確定します。確定後は「確定解除」で解除できます。

### CSV出力

各セクションのヘッダー右側にある「CSV出力」ボタンでダウンロードできます。

**出力列**

| 列 | 内容 |
|---|---|
| 種別 | 介護保険レンタル / 販売 / 自費レンタル |
| 卸会社 | 卸会社名 |
| 利用者名 | 利用者の氏名 |
| あおぞらID | 利用者ID |
| 弊社品目 | カイポケ上の品目名（未紐づけの場合「（未紐づけ）」） |
| 卸品目 | 卸請求書の品目名（未紐づけの場合「（未紐づけ）」） |
| 卸金額 | 卸請求金額（返品は負の値） |

> 「（未紐づけ）」行が残っている場合、正しい利用者への紐づけ作業が必要です。
