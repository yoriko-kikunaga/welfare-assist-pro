# WelfareAssist Pro 操作マニュアル

## アプリ概要

**WelfareAssist Pro（福祉用具マネージャー）** は、福祉用具専門相談員の業務を一元管理するWebアプリです。

- **URL**: https://welfare-assist-pro.web.app
- **対応ブラウザ**: Google Chrome（推奨）、Edge
- **データ更新**: 毎日 00:00 JST に自動同期（Google Sheets・Kintone 連携）

---

## ログイン

1. URLにアクセス
2. Googleアカウント（会社メールアドレス）でログイン
3. 初回ログイン時は管理者に権限付与を依頼してください

---

## 画面構成

左サイドバーと右のメインエリアで構成されています。

- **左サイドバー**：利用者一覧・検索・各種機能ボタン
- **メインエリア**：利用者詳細または各業務ページ

### サイドバーのボタン一覧

| ボタン | 色 | 機能 |
|--------|-----|------|
| 福祉用具集計 | 空色 | 施設別・Status別・事業所別の福祉用具利用者集計 |
| 売上・仕入突合 | 青緑色 | 卸会社請求書との突合作業 |
| 月次売上処理 | 紫色 | 月次売上の確認・CSV出力・確定 |
| 変更情報一覧 | 青色 | 新規・入院・退院・解約の一覧 |
| ベッド管理 | 藍色 | 自社ベッドの在庫・QR・償却・クリーニング管理 |
| レセプトチェック | 薔薇色 | 介護保険レンタル請求前確認 |
| ヘルプ | グレー | 操作マニュアル（本ドキュメント） |

### 利用者フィルター

| ボタン | 表示対象 |
|--------|---------|
| 全員 | 全利用者（8,000件以上） |
| 福祉用具（500） | 福祉用具利用中のみ |

通常業務では **「福祉用具」フィルター** をONにして使用してください。

---

## データの仕組み

| データ種別 | 更新タイミング | 備考 |
|-----------|-------------|------|
| 利用者基本情報（氏名・住所等） | 毎日 00:00 自動 | 読み取り専用 |
| 編集内容（事業所・介護度・議事録等） | 保存ボタンで即時反映 | 自動更新後も保持される |
| 介護保険レンタル | 月次CSVインポート（手動） | カイポケから取込 |
| 変更情報 | 保存ボタンで即時反映 | 自動更新後も保持される |
| 突合・在庫データ | 操作時即時反映 | 自動更新の影響なし |

> **安心ポイント**: 毎日 00:00 の自動更新後も、アプリで入力した情報（議事録・変更情報・事業所設定など）は消えません。
