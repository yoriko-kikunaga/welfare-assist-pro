## 2. Kintone連携データがアプリに反映されない問題

### 問題
- Kintoneで更新された退院日（2026-01-17）がアプリで表示されない
- 代わりにプレースホルダー値「9999-12-31」が表示される

### 原因
`firestoreService.ts`のchangeRecordsマージロジックが、Firestoreの古いデータをclients.jsonの最新データより優先していた

```typescript
// 旧ロジック（問題あり）
changeRecords: (edits.changeRecords?.length ? edits.changeRecords : baseClient.changeRecords) || []
// → Firestoreにデータがあれば、clients.jsonを完全に無視
```

### 修正内容 (`src/services/firestoreService.ts`)

```typescript
// 新ロジック
function mergeChangeRecords(baseRecords, firestoreRecords) {
  // 1. baseRecords（clients.json = Kintone最新）を全て使用
  const merged = [...baseRecords];
  const baseIds = new Set(baseRecords.map(r => r.id));

  // 2. Firestoreの手動追加レコードのみ追加
  firestoreRecords.forEach(record => {
    if (baseIds.has(record.id)) return;           // 既にbaseにある
    if (record.id.startsWith('kintone-')) return; // Kintoneレコードはbaseが最新
    merged.push(record);                          // 手動レコードのみ追加
  });

  return merged;
}
```

**マージ優先度:**
| レコード種別 | データソース |
|-------------|-------------|
| Kintone連携 (`kintone-*`) | clients.json（常に最新） |
| 手動追加 | Firestore |
